Enable voice on this phone

Browser microphones require a trusted HTTPS connection. JARVIS can provide one locally without enabling any public tunnel.

1
Download the JARVIS local CA
Install it as a CA certificate in Android security settings. This is a one-time setup for this phone.
2
Return here
Then reopen JARVIS on the same HTTPS port 8000. Chat and Voice use the same secure connection.
3
Allow microphone
Tap Voice again and choose Allow when the browser asks for microphone permission.
